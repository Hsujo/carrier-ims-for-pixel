# SIM 4G/5G 磁贴实施计划

## 目标与交互

Android 13+ 新增 SIM1、SIM2 两个快捷设置磁贴，按系统逻辑卡槽切换该订阅的用户网络偏好。亮起表示允许 NR，关闭表示禁用 NR；副标题明确显示「5G 已允许 / 5G 已关闭」。允许 NR 不保证实际连接 5G，禁用 NR 保留其他网络类型，不强制 LTE-only。锁屏点击先解锁，不改变默认数据卡。

## 实施步骤

1. 从远程 `master` 创建 `feat/sim-4g-5g-tiles`。
2. 新增纯 Kotlin 掩码规则，只翻转 NR 位，保留包括未知高位在内的其他位。拒绝空掩码及关闭唯一可用的 NR，防止写入零掩码。
3. 新增 `NetworkModeModifier`，沿用后台 instrumentation 和 Shizuku shell 权限委托。校验 subId 与卡槽仍对应有效订阅，检查基带 NR 支持，再调用 `TelephonyManager.getAllowedNetworkTypesForReason(USER)`。切换时同一次调用内完成读、改、写、读回验证；仅修改 USER 原因，不写运营商或省电原因，不改 CarrierConfig，也不重启 IMS。
4. 在 `ShizukuProvider` 提供结构化结果，沿用全局 instrumentation 互斥和超时。基带能力查询使用 Android 13+ 公开的 `getSupportedRadioAccessFamily()`，失败明确返回错误，不能猜测支持情况。
5. 新增共享磁贴基类与两个服务。每卡共享互斥锁，连点不会排队执行第二次切换。服务销毁或协程取消也释放锁。每次下拉重新读取系统状态，失败提示并读回实际偏好。
6. 注册 Manifest 服务和 instrumentation，新增单色信号图标与中英文文案，更新 README 和 CHANGELOG。
7. 验证掩码规则、全量单元测试、debug APK 构建、lint 和变更检查。完成后提交功能分支，再合并进 `master` 并推送；合并前检查远程是否前进，禁止强推。

## 自动验证

- LTE、旧网络位及未知高位在关闭 NR 后保持原样，恢复 NR 后完整还原。
- 空偏好和 NR-only 的关闭操作被拒绝。
- `:app:testDebugUnitTest`、`:app:assembleDebug`、`:app:lintDebug`。
- 检查两个磁贴均要求 `BIND_QUICK_SETTINGS_TILE`，无新增对外 Activity，无新增普通权限请求。

## 真机验收（需要 Pixel 与 Shizuku，构建检查无法替代）

| 场景 | 预期 |
|---|---|
| SIM1/SIM2 分别开关 | 只改变目标订阅 NR 位，另一卡和默认数据卡不变 |
| 从系统设置修改网络偏好后重新下拉 | 磁贴显示最新 USER 设置 |
| 连续快速点击或切换中收起面板 | 不产生额外排队切换，下次下拉读取实际值 |
| 锁屏点击 | 解锁后执行 |
| Shizuku 停止或撤销授权 | 显示需要授权；点击打开 App |
| 卡槽空、停用 eSIM、切换订阅 | 不对失效或其他卡槽的订阅写入 |
| 不支持 NR、能力查询异常、API 拒绝 | 显示不可用并记录日志 |
| 写入被拒绝、返回超时或读回不同 | 提示未能确认成功，重新读取实际偏好 |
| USER 允许但运营商/省电禁止 NR | 仍显示用户偏好；不承诺当前连接 5G |
| 禁用 NR 后信号变化 | 可回落 LTE 或其他原有网络，语音/数据按系统流程重新注册 |
| Android 13、14、15、16 及仓库支持的 17 构建 | 检查特权权限、基带能力查询及磁贴状态是否兼容 |

## 已知边界

磁贴按原有 SIM 磁贴的系统逻辑卡槽编号工作。网络实际选制式由系统、运营商、套餐和覆盖共同决定。两次系统调用之间无法对 SIM 热切换或外部设置写入提供跨进程事务保证；写入前再次校验订阅，写入后校验结果。读回不一致时不盲目回滚，以免覆盖其他来源的最新设置。

## 开发验证结果

- 全量单元测试：17 个测试类、94 项测试，零失败、零错误（包含新增的 2 项掩码规则测试）。
- Debug APK 构建通过，Manifest、双语资源与图标 XML 检查通过，`git diff --check` 通过。
- 全量 lint 未通过：未修改的 `master`（`ce73720`）与功能分支都报告 170 个既有错误，错误集合一致，涉及已有权限注释、Compose 资源读取及历史缺失翻译。新增功能未增加 lint 错误。功能分支额外的两条依赖版本提示来自未修改的 `libs.versions.toml` 和在线依赖元数据查询。
- 此环境没有连接 Pixel，以上真机验收仍待执行。
